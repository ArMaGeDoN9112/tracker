# 05: Сводки питания за период

Status: resolved
Type: task
Blocked by: 02

**What to build:** пользователь просматривает дневные итоги и средние питания за выбранный период, понимает полноту и основу расчёта и открывает исходный день для проверки.

**Основание:** [спецификация этапа](../spec.md), разделы «Числа и калькулятор еды», «День и сводки питания», «API, сохранение и интерфейс», «Testing Decisions».

- [x] Доступны последние 7 и 30 московских календарных дней до выбранного конца включительно и произвольные обе даты. По умолчанию конец — сегодня; фактические границы видны, более старая история доступна.
- [x] Сводка содержит дневные итоги, число приёмов и число дней с неудалённой едой. День с полностью неизвестной ценностью считается днём с едой; вода не увеличивает этот счётчик. Расчёт использует сохранённые строки независимо от актуального каталога и типа еды.
- [x] Каждый показатель имеет отдельное среднее: сумма точных известных вкладов делится на число дней хотя бы с одним известным значением этого показателя. Дни без еды и полностью неизвестные дни не подставляются нулями; известный ноль входит в знаменатель.
- [x] Отдельно видны знаменатель показателя, общее число дней с едой и число неполных дней. Неизвестные значения в любом дне с едой помечают среднее неполным, даже если день не вошёл в знаменатель; без известных дней результат неизвестен. Средние округляются независимо от показанных дневных сумм.
- [x] Контрольный пример спецификации воспроизводится: 10 г плюс неизвестное, полностью неизвестный день и пустой день дают 2 дня с едой, знаменатель 1 и неполное среднее 10 г. Добавление известного дня с 0 г даёт знаменатель 2 и среднее 5 г.
- [x] Переход из сводки открывает соответствующий день питания и переводит фокус к истории без потери текущего черновика. Правки, переносы, удаление и восстановление обновляют связанные сводки; запоздалый ответ старого периода не подменяет текущий.
- [x] Приватный API, состояния загрузки/пустоты/ошибки и доступное отображение неполноты соответствуют спецификации; обновлены API и действующие правила продукта. HTTP API на файловой SQLite и desktop/phone Chromium проверяют периоды, московскую полночь, знаменатели, обновления и переход в день.

## Answer

Реализованы приватный API периодов, точные дневные итоги и средние по сохранённым
строкам с независимыми знаменателями, известным нулём и текстовой неполнотой.
В питании доступны 7/30 дней и произвольные даты, переход к истории дня без
потери черновика, обновление после мутаций и защита от запоздалых ответов.
Обновлены API и действующие правила продукта.

Проверки: 317 backend, полный Chromium 124 и финальные 8 адресных сценариев,
mypy и TypeScript/production build. Независимое ревью стандартов: 0 замечаний;
замечание спецификации о подписи исправлено, повторное ревью: 0.
