## Работа

Выделить классы экспорта и пользовательских операций backup/restore/status. Переиспользовать экспорт для проверки схемы снимка, не смешивая экспорт с SQL. Сохранить порядок внешних эффектов, блокировку, manifest/checksum, pending/verified, отзыв сессий после restore и ротацию. Сохранить python -m diary.backup и содержимое bundle, нужное для восстановления.

## Приёмка

Экспорт совместим со схемой и примерами; проверены снимок при записи, восстановление в новый каталог, целостность, недоступный restic, нехватка места, прерывание, конкуренция и отказ проверки. Успех не отмечается до проверки; прежние точки сохранены при сбое.
Проверки запускать через Docker Compose. Сохранять правила code-feedback и инварианты плана.

## Реализация

- `application/export.py`: класс `ExportDiary`, типизированные данные полного
  снимка и порт чтения. `infrastructure/export.py`: все SELECT через SQLAlchemy
  Core на одном соединении с явным `BEGIN`, ошибки SQL сохраняют причину.
- `interfaces/export.py`: прежние DTO v3 и общий сериализатор без SQL;
  переиспользуется HTTP и проверкой схемы резервной копии.
- `application/backup.py`: классы `CreateBackup`, `RestorePoint`, `VerifyBackup`,
  `GetBackupStatus`, `RunBackup`, DTO, enum и типизированный отказ `BackupFailure`.
  Порядок lock/status/pending/readback/revoke/verified/success/rotation сохранён;
  часы и monotonic передаются явно. Файлы/restic не объявлены общей SQLite UoW.
- `infrastructure/backup.py`: Online Backup API, integrity/foreign keys/schema,
  checksum/manifest, приватные файлы, flock, restic и отзыв сессий.
  Адаптер переводит инфраструктурные отказы с сохранением исходной причины.
- HTTP и CLI используют сценарии через `bootstrap.py`; `python -m diary.backup`
  остаётся тонкой совместимой точкой входа. Весь пакет `diary` по-прежнему
  копируется в bundle, включая новые слои; Dockerfile и формат bundle не менялись.
- Старый `diary/export.py` удалён, новые временные мосты не добавлены.
  Документация путей DTO и эксплуатационного устройства обновлена;
  описание загрузки статуса согласовано с текущим отсутствием фонового опроса.
