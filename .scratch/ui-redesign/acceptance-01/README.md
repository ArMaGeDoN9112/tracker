# Приёмка задачи 01

Проверены только вход, навигация, каркас и сохранность состояния из
[задачи 01](../issues/01-navigation-and-state.md). Переработка содержимого разделов
остаётся в задачах 02–06.

## Среда

- Chromium в Linux-контейнере `tracker-e2e`, настоящий API и изолированная синтетическая БД.
- Актуальные `diary/` и `scripts/` примонтированы из рабочего дерева; сервер из старого образа не используется.
- Визуальная проверка: 375, 390, 768, 1280 и 1440 CSS px. На каждой ширине открыты четыре раздела, проверено отсутствие горизонтального переполнения страницы.
- Проверены клавиатурный переход, видимый фокус и размеры пунктов навигации не менее 44 × 44 px, отмена удаления из настроек.
- Снимки получены скриптом [visual-qa.spec.ts](visual-qa.spec.ts). Это проверка поведения и визуальное доказательство, без сравнения пикселей.

## Результаты

- HTTP/сервер: **189 passed**, полный актуальный набор `pytest -q` в Linux-контейнере с текущими исходниками, включая резервирование. Два предупреждения существующих зависимостей.
- Отдельная визуальная браузерная проверка: **1 passed**.
- Итоговый браузерный набор: **38/38 passed**, desktop и phone, включая сохранность трёх черновиков, повторы после настоящего commit, фоновый 401, отложенный CSRF и срок отмены между разделами.
- TypeScript и production-сборка Vite прошли. Сохраняется предупреждение Vite о размере основного bundle; демонстрационные варианты в production не включаются.
- Контраст текста на поверхности: основной **15,04:1**, вторичный **7,53:1**, ошибка **10,27:1**; активная навигация **8,54:1**, граница кнопки **4,24:1**.
- Ревью правил репозитория: замечаний нет. Замечание ревью спецификации об ожидающем CSRF-запросе формы исправлено в `8bd3df1`: запрос привязан к сессии, повторный вход не продолжает отправку автоматически. Проверены RED/GREEN и итоговый браузерный набор; повторное ревью без замечаний.

## Границы проверки

- Настоящий iPhone/Safari не проверен; мобильный Chromium не выдаётся за реальное устройство.
- Публикация, VPS и эксплуатационная готовность внешних копий не входят в задачу.
- Прямое скачивание экспорта остаётся браузерным защищённым запросом. Оно не проходит через JavaScript-обработчик 401; проверка взаимодействия такого скачивания со входом относится к задаче 06. Защиту самого API проверяют серверные тесты.
