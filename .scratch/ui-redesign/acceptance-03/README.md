## Регрессии

Графики проверены в зоне устройства America/Los_Angeles. Настоящий API
подтверждает периоды 7/30 дней и произвольный, включённые границы, взвешенное
среднее 8,0 по трём измерениям (4,0/8,0/12,0), пропуск пустого дня и равенство
среднего/минимума/максимума при одном измерении. Три линии сохраняют разрывы.
Подсказка клавиатурой показывает московскую дату и единицы.

Точка, столбец и Enter на дне таблицы открывают собственную дату, фокусируют
хронологию и сохраняют сахар, подколку, причину, комментарий и время черновика.
Создание, исправление с переносом, удаление и отмена перечитывают сводку;
период сохраняется при переходах. Задержанный настоящий ответ старого периода
не заменяет новый. Загрузка, ошибка с повтором и пустое состояние различаются.

Общие сценарии авторизации, сохранения, конфликтов, потерянных ответов,
срока отмены, расписания, временной базы, экспорта и резервирования прошли
в полном браузерном наборе. Формат данных и серверные расчёты не изменены.

## Воспроизведение

Полный обычный запуск: `docker compose run --build --rm e2e`.
Для этой приёмки использовался существующий образ `diary-layout-a-impl-e2e`
с текущими `frontend/src` и `frontend/e2e`, подключёнными только для чтения.
Для отдельных снимков состояний задавался `DIARY_ACCEPTANCE_DIR=/evidence`
и каталог приёмки подключался к `/evidence`.

Визуальный сценарий запускается отдельно: подключить этот каталог к
`/app/frontend/e2e:ro` и `/evidence`, текущий `frontend/src` к
`/app/frontend/src:ro`, выполнить `npm --prefix frontend run test:e2e --
visual-qa.spec.ts --project=desktop` в том же образе.

Реализация: `716378d`, `f03c9e7`; связь с решениями:
[Decisions-so-far](../map.md#decisions-so-far).

## Ограничения

Настоящий iPhone/Safari и ручная проверка screen reader недоступны.
Проверка phone в Chromium означает эмуляцию размера и взаимодействий.
VPS, внешние резервные копии и эксплуатационный допуск не входят в задачу.
