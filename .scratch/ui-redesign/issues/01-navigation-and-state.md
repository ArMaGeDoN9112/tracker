# 01: Вход и навигация без потери состояния

**What to build:** владелец входит через отдельный экран, переходит между четырьмя
разделами и возвращается к прежнему черновику или незавершённой операции.
Навигация и каркас получают оформление A; существующие рабочие разделы доступны
на протяжении дальнейшей переработки.

**Blocked by:** None (can start immediately).

**Status:** resolved

**Type:** task

Основание: [спецификация](../spec.md), истории 1, 4–10, 24–27, 36, 52, 58, 60–62.
Визуальное направление: [вариант A](../prototype.md), коммит `817526a`.


- [x] Отдельный вход, компактный аккаунт/выход, боковая навигация на компьютере и нижняя на телефоне. Четыре раздела и два представления базы открывают существующие рабочие функции, а не заглушки.
- [x] Каркас использует палитру, системную типографику и семантические стили A; стили не ломают ещё не переоформленные формы и графики. Неактивные формы исключены из фокуса и средств доступности.
- [x] Адрес отражает раздел и выбранный день. Прямое открытие, перезагрузка, назад/вперёд согласованы; неизвестный раздел и неверная дата обработаны по спецификации. Содержимое записей и секреты не попадают в URL.
- [x] Необходимая перестройка владения состоянием выполнена до переключения представлений: все три формы сохраняют поля, режим правки, UUID, исходные запросы, конфликты и ожидаемые редакции. Переходы не отправляют формы и не отменяют уже отправленные операции.
- [x] Отмена последнего удаления записи и временной базы доступна вне исходного экрана и сохраняет серверный остаток срока без перезапуска таймера. Скрытие раздела не теряет обновления зависимых данных.
- [x] При 401 личные разделы скрыты, повторный вход сохраняет черновики и требует явного продолжения. Действующий вход после перезагрузки, независимый выход, Unicode-пароли, автозаполнение и прежняя защита сохранены.
- [x] Браузер проверяет навигацию, три черновика, потерю ответа после настоящего сохранения с тем же повтором, повторный вход и отмену между разделами. Существующие проверки обновлены для навигации и проходят; TypeScript и сборка проходят.
- [x] Каркас проверен на узком и широком экране, клавиатурой, с видимым фокусом и достаточными областями нажатия; рабочий выпуск не включает баннер и переключатель прототипов.

## Answer

20 октября 2026: реализовано в интеграционной ветке `codex/ui-navigation-state`,
коммиты `77b1d84` и `8bd3df1`.

Четыре раздела и два представления базы открывают существующие операции.
History API хранит раздел и день, формы остаются смонтированными и скрываются
от фокуса при переходах. Поля, правка, конфликты, UUID и исходные запросы сохраняются;
отмена каждого вида доступна через общий каркас с прежней серверной границей срока.
Общий обработчик 401 скрывает личные разделы, а отложенные CSRF-запросы форм
привязаны к прежней сессии и не отправляют изменения после повторного входа автоматически.

Проверки: TypeScript и production-сборка; **38/38** браузерных сценариев desktop/phone
с настоящим текущим API; **189** серверных тестов. Дополнительно проверены каркас
на ширинах 375/390/768/1280/1440 px, клавиатура, фокус, размеры навигации и контраст.
Обе оси ревью завершены, выявленная гонка CSRF исправлена и проверена.
