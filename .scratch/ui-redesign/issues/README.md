01 сначала отделяет навигацию от времени жизни форм. Это необходимая перестройка
существующего интерфейса, включённая в работающий сценарий входа и переходов.
Существующие разделы продолжают работать до их оформления задачами 02–06.

02–06 опираются только на 01: серверные операции уже существуют. Графики могут
переходить к ещё не переоформленному дневнику; редактор временной базы не требует
нового оформления редактора расписания. Искусственной цепочки между ними нет.
Независимость по смыслу не означает автоматический запуск агентов параллельно;
общие стили и интеграционные точки нужно согласованно менять.

Каждая задача включает своё оформление, рабочие операции, состояния, доступность
и браузерную проверку. Тесты и исправление обнаруженных регрессий не откладываются
на 07; финальная задача проверяет сочетание уже законченных сценариев.

Общие ограничения: прежние API, SQLite, точность, серверная валидация,
сессии/Origin/CSRF/no-store, приватность и отсутствие постоянного хранения черновиков.
Производственные заглушки из прототипа не используются. Изменений схемы и API нет.
Визуальный первоисточник — A в коммите `817526a` ветки `codex/prototype-diary-redesign`.
