настройки с экспортом и достоверным статусом копий, затем общая приёмка приложения.
Объединяет прежние задачи 05–07 без сокращения требований спецификации.

**Blocked by:** 01, 02, 03, 04 (все resolved).

**Status:** ready-for-human

**Type:** task

Основание: [спецификация](../spec.md), истории 22–27, 36, 48–62;
сквозная приёмка всех историй. Уже выполненное в 01–04 переиспользуется.

## Временная база

- [x] Редактор и полная история оформлены в стиле A. Создание: начало, положительная длительность, процент. Правка: начало, процент, заданное окончание с сохранением исходной длительности. До подтверждения показаны период влияния, заданное/эффективное окончания и влияние на соседей; замещение прекращает предыдущую базу без возобновления. Подписи не обещают управление помпой.
- [x] Существующие операции сохраняют создание, историческую правку, досрочное и историческое завершение, мягкое удаление и отмену. Серверная валидация, процент, округление, неизвестная база и переходы расписания не меняются.
- [x] Конфликт редакции или занятого начала сохраняет черновик и позволяет явно сравнить актуальные данные. Черновик, режим правки, исходный запрос и UUID переживают навигацию и повторный вход без скрытой отправки; потеря ответа после commit допускает безопасный повтор.
- [x] Отмена доступна на других экранах с прежним серверным сроком 30 секунд, без продления и предложения устаревшего действия после повторной операции. После подтверждения обновляются история, база формы и дня.

## Настройки, экспорт и копии

- [x] Настройки в стиле A разделены на аккаунт, экспорт и резервирование. Аккаунт и выход доступны без большого вводного блока над дневником.
- [x] Прямое защищённое скачивание полного UTF-8 JSON сохраняет формат, всю историю, мягкие удаления и no-store, независимо от выбранного дня/периода. Рядом предупреждение о приватности. При истёкшей сессии успех не объявляется, повтор после входа явный; файл не публикуется и не сохраняется приложением в клиентских хранилищах.
- [x] Каркас и настройки используют одно состояние копий, обновляемое раз в минуту при действующем входе. Внешний/локальный успех, проверка восстановления, ошибки и просрочка 26 часов различаются; ошибка чтения означает неизвестное состояние. Локальное учение не выдаётся за внешнюю копию, успех требует подтверждения сервера.
- [x] Краткое предупреждение на других экранах ведёт к подробностям без потери черновика. До входа личные данные недоступны. Механизм копирования и планировщик не меняются.

## Общая приёмка и завершение

- [x] Браузер с настоящим API проверяет замещение и окончания временной базы, завершение задним числом, конфликты, удаление/отмену, потерю ответа и повторный вход; фактический экспорт старой и удалённой истории, недействующую сессию; все состояния копий и переход из предупреждения. Загрузка, ошибка, повтор, пустота и успех различимы.
- [x] Проверены совместные переходы: ввод → график → исходный день → правка/перенос → обновлённая сводка; изменение базы → обновление формы/истории; предупреждение копий → настройки → возврат к черновику. Для всех трёх форм проверены черновики, неопределённый результат после настоящего commit, повторный вход без автоотправки, конфликты и доступная отмена без продления срока. Интеграционные дефекты исправлены.
- [x] Проходят существующие HTTP-тесты на временной SQLite, браузерный набор desktop/mobile Chromium, TypeScript и production-сборка. В выпуске нет синтетических записей, фиксированной демонстрационной базы, переключателя вариантов и заглушек. Прототип сохранён отдельно как первоисточник.
- [x] На 375/390, 768, 1280 и 1440 px проверены все разделы, длинные комментарии и большая история, контраст, нажатия, подписи, клавиатура, фокус, объявления результатов, reduced motion и отсутствие перекрытий форм/навигации. Скриншоты фиксируют результат.
- [ ] Ручная приёмка на настоящем iPhone/Safari: клавиатура, фокус, дата/время, достижимость сохранения, safe area, нижняя навигация и JSON. Если устройства нет, записано конкретное непроверенное условие; эмуляция не выдаётся за проверку устройства, задача не объявляется полностью завершённой.
- [x] Пользовательская инструкция описывает новую навигацию, сохранение состояния и предел черновиков в памяти вкладки. API, схема, экспорт и отсутствие постоянного клиентского хранения сохранены. Итог содержит фактические результаты и ограничения; UI-проверки не подменяют эксплуатационный допуск к реальным данным.
