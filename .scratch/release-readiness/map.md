# Состояние приёмки

## Notes

Действующие правила и будущий продуктовый план перенесены в `docs`.
Старые подробные отчёты доступны в Git (`23acfdb`). В текущей папке остаются
локальная проверка восстановления, реальные устройства и отложенный допуск.

## Decisions-so-far

- 20 октября 2026: по указанию пользователя работаем только локально. VPS,
  домен, внешнее хранилище и планировщики на сервере не настраиваем.
- Регулярная проверка восстановления уже реализована вместе с резервированием:
  `verify`, чтение всех блоков restic, изолированное восстановление и проверка DTO,
  сохранение результата/ошибки, недельные шаблоны systemd. Повторная реализация не нужна.
- [Локальная часть прежней задачи 10 закрыта](issues/01-local-recovery.md#answer):
  8/8 проверок настоящего локального restic/SQLite за 147,88 с и 6/6 браузерных
  сценариев статуса за 8,6 с. Рабочие тома не использовались; серверная установка
  и внешнее восстановление сохраняются в задаче 04.
- Мобильный Chromium не закрывает ручную приёмку настоящего iPhone/Safari.

## Fog

- Для задачи 02 нужны фактическая версия iOS/Safari и результаты на устройствах владельца.
- Для задач 03–04 в будущем потребуются сведения об окружении, хранилище и успешное
  внешнее восстановление. Сейчас эти сведения не запрашиваются и не выдумываются.
