# 06: Исправление и завершение временной базы

**What to build:** пользователь исправляет временную базу, завершает её раньше, корректирует окончание задним числом или удаляет запись с возможностью отмены и видит изменившийся период истории.

**Blocked by:** 05.

**Status:** ready-for-agent

**Type:** task

- [ ] Доступны редактирование начала и процента, досрочное завершение и исправление заданного окончания задним числом. Окончание раньше начала отклоняется; равенство означает нулевой период. Исходная длительность сохраняется.
- [ ] До подтверждения показан затрагиваемый период. Изменение начала, окончания или удаление атомарно пересчитывает эффективные границы соседей, не сохраняя искусственно обрезанные заданные окончания.
- [ ] Удаление мягкое; без удалённой базы действует расписание либо другая временная база по правилам истории. Отмена в течение 30 секунд по серверному времени восстанавливает действие; конфликт занятого начала объясняется без перезаписи.
- [ ] Изменение, удаление и восстановление требуют актуальной редакции и UUID операции. Проверка редакции, квитанция и все изменения атомарны; повтор безопасен, конфликт сохраняет пользовательский ввод для сравнения.
- [ ] Хронология и база событий обновляются только для затронутого периода; после окончания применяется обычное расписание без фоновой задачи. Удалённые сущности остаются для экспорта и резервирования.
- [ ] HTTP-проверки покрывают исторические правки, соседние границы, удаление B и отмену, конфликт начала и редакции, гонки и границу отмены. Браузер проверяет завершение задним числом и видимость затронутого периода; миграции сохраняют всю историю.
