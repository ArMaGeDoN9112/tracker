# 01: Вход в личный дневник

**What to build:** владелец локально запускает приложение, создаёт единственный аккаунт административной командой и входит с телефона и компьютера. Личные данные доступны только с действующей сессией. Реализация следует согласованной спецификации дневника диабета.

**Blocked by:** None (can start immediately).

**Status:** resolved

**Type:** task

- [x] FastAPI и React + TypeScript + Vite запускаются локально по инструкции; зависимости зафиксированы для проверенного локального окружения. SQLite создаётся миграциями и сохраняет данные после перезапуска. Проверка рабочего VPS не является условием разработки.
- [x] Единственный аккаунт создаётся административной командой; повторное создание отклоняется. Пароль вводится без отображения, имеет длину 15–1024 символа и хешируется Argon2id через pwdlib; секреты не попадают в аргументы процесса, репозиторий или логи.
- [x] Вход создаёт непрозрачный случайный токен не менее 256 бит, в БД хранится хеш. Cookie Secure, HttpOnly, SameSite=Lax и серверная сессия истекают через 30 дней от входа. Токен заменяется при входе и не хранится в localStorage.
- [x] Сессии устройств независимы; выход отзывает текущую. Административная смена пароля атомарно отзывает все сессии; инструкция позволяет проверить новый вход и отказ старых cookie.
- [x] Все предметные маршруты защищены общим правилом доступа. Изменяющие запросы, включая вход и выход, проверяют Origin и CSRF; предварительный токен обновляется после входа. Чужой CORS запрещён, приватные ответы имеют no-store, production-документация API закрыта или отключена.
- [x] Не более пяти неудачных попыток входа за 15 минут по источнику и логину допускаются до дорогой проверки пароля; счётчики переживают перезапуск. Нет раскрытия существования логина или бессрочной блокировки; заголовкам адреса доверяют только от проверенного прокси.
- [x] Экран входа адаптивен, с тёмной темой, подписями, видимым фокусом и доступными с клавиатуры элементами не меньше 44 × 44 CSS-пикселей. Пароли, cookie и личные данные не журналируются.
- [x] HTTP-проверки с настоящей файловой SQLite и миграциями подтверждают доступ, CSRF, ограничение входа, сроки и отзыв сессий; браузерный сценарий проверяет вход и выход. Используются синтетические данные.

## Answer

Реализованы локальный FastAPI/React, первая миграция SQLite, административное создание аккаунта и смена пароля, Argon2id, сессии устройств, Origin/CSRF, глобальный запрет доступа и постоянное ограничение попыток входа. Инструкция: [README](../../../README.md). Решения: [Decisions-so-far](../map.md#decisions-so-far).

Проверки: 10 HTTP-тестов с файловой SQLite и миграциями; mypy; TypeScript и production-сборка; два браузерных сценария Chromium (desktop/mobile), включая Unicode-пароль из 600 emoji. Пароли в тестах только синтетические.
