# 08: Полный документированный JSON-экспорт

**What to build:** владелец скачивает всю накопленную историю в документированном JSON, пригодном для независимой проверки и переноса данных.

**Blocked by:** 03, 06.

**Status:** ready-for-agent

**Type:** task

- [ ] В настройках доступен прямой download полного экспорта после проверки сессии с no-store, без публичной ссылки. Рядом предупреждение о личных сведениях и включении мягко удалённых данных.
- [ ] Экспорт представляет согласованный снимок на один момент, не зависит от выбранного периода, пагинации или возраста истории; конкурентные изменения не смешивают состояния разных моментов.
- [ ] Есть версия схемы, время экспорта, Europe/Moscow, единицы, все записи, версии расписания с интервалами, временные базы, настройки и несекретные сведения аккаунта. Сохраняются UUID, точность, null, нули, редакции, времена и удаления; для временной базы — исходная длительность, процент, заданное и производное окончание.
- [ ] Нет хешей паролей, сессий, CSRF, ключей резервирования, квитанций и технических журналов. Формат не вводит отсутствующие предметные каталоги или пользовательский импорт.
- [ ] Каждое поле, единицы, точность, причины подколки, времена, полуоткрытые границы, удаления и расчёт временной базы документированы. Есть валидный пример, JSON Schema и правило версии при несовместимом изменении.
- [ ] HTTP-проверки валидируют схему и сверяют полную синтетическую историю, включая старые и удалённые данные, Unicode и конкурентное изменение. Браузер проверяет скачивание; на финальной приёмке проверяется имя и читаемость файла на iPhone и компьютере.
