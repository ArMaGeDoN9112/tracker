# 08: Полный документированный JSON-экспорт

**What to build:** владелец скачивает всю накопленную историю в документированном JSON, пригодном для независимой проверки и переноса данных.

**Blocked by:** 03, 06.

**Status:** resolved

**Type:** task

- [x] В настройках доступен прямой download полного экспорта после проверки сессии с no-store, без публичной ссылки. Рядом предупреждение о личных сведениях и включении мягко удалённых данных.
- [x] Экспорт представляет согласованный снимок на один момент, не зависит от выбранного периода, пагинации или возраста истории; конкурентные изменения не смешивают состояния разных моментов.
- [x] Есть версия схемы, время экспорта, Europe/Moscow, единицы, все записи, версии расписания с интервалами, временные базы, настройки и несекретные сведения аккаунта. Сохраняются UUID, точность, null, нули, редакции, времена и удаления; для временной базы — исходная длительность, процент, заданное и производное окончание.
- [x] Нет хешей паролей, сессий, CSRF, ключей резервирования, квитанций и технических журналов. Формат не вводит отсутствующие предметные каталоги или пользовательский импорт.
- [x] Каждое поле, единицы, точность, причины подколки, времена, полуоткрытые границы, удаления и расчёт временной базы документированы. Есть валидный пример, JSON Schema и правило версии при несовместимом изменении.
- [x] HTTP-проверки валидируют схему и сверяют полную синтетическую историю, включая старые и удалённые данные, Unicode и конкурентное изменение. Браузер проверяет скачивание.
- [ ] На финальной приёмке проверить имя и читаемость файла на реальном iPhone/Safari и компьютере владельца.

## Answer

Реализован защищённый `GET /api/export` и прямое скачивание из настроек с предупреждением
о личных и мягко удалённых данных. Явный BEGIN и первое чтение аккаунта устанавливают
единый снимок SQLite для всех выборок, включая производные окончания. Все предметные
данные читаются без периода и пагинации; секреты и служебные таблицы исключены.
Миграция не требуется.

Формат v1 сохраняет RFC 3339 UTC с миллисекундами и десятичные строки 1/1/2 знака;
используются существующие сериализаторы. Настройки первой версии фиксированы
(Europe/Moscow, dark). Удалённая временная база имеет `effective_ends_at: null`,
а исходные поля и длительность сохраняются. Поля, единицы, правила расчёта и версий,
JSON Schema и валидный пример — в [документации](../../../docs/export/README.md).

Проверки в Docker Compose: 181 HTTP-тест (7 новых), mypy, TypeScript и production-сборка;
22 Playwright-сценария desktop/mobile Chromium (2 новых). Проверены 105 старых записей,
удаления, редакции, Unicode, предельные точные числа, null и нули, все версии расписаний,
исходные и производные поля временной базы, отзыв/истечение сессии и конкурентная запись
во время экспорта. Файл реально скачивается и читается как UTF-8 JSON.

Standards: 0 открытых замечаний. Spec: 0 открытых замечаний после исправления формата
времён и чисел, повторное ревью выполнено. Реальный iPhone/Safari и устройства владельца
не проверялись; инструкция финальной ручной приёмки сохранена в документации.
Память при сборке файла растёт пропорционально всей истории.

Решения зафиксированы в [Decisions-so-far](../map.md#decisions-so-far).
