# Diabetes diary — implementation map

## Notes

- Задача [02: Быстрый ввод и просмотр дня](issues/02-quick-entry-and-day.md) реализована: независимые поля, историческое московское время, атомарные квитанции повторов и сохранение черновика при повторном входе.
- Задача [01: Вход в личный дневник](issues/01-private-access.md) реализована по [спецификации](spec.md). Инструкция локального запуска и смены пароля: [README](../../README.md).
- Проверено на Windows с Python 3.12.14 и Node.js 22.19.0; зависимости закреплены в `uv.lock` и `frontend/package-lock.json`.

## Decisions-so-far

- Записи: миграция 002, сахар и подколка в целых десятых, UTC-миллисекунды; чтение дня в Europe/Moscow без обрезания, стабильный порядок времени события/создания/UUID. До расписаний база `null`. `tzdata` обеспечивает историческую зону и на Windows.
- Повтор создания: UUID и хеш нормализованного запроса, запись и квитанция в одной `BEGIN IMMEDIATE` транзакции. После неизвестного результата форма удерживает исходный запрос; после квитанции перечитывает день. Черновик хранится только в памяти открытой вкладки, без офлайн-очереди и скрытой отправки после входа.
- Проверки после задачи 02: 44 HTTP-теста, mypy, TypeScript и production-сборка; 8 браузерных сценариев desktop/mobile Chromium, в том числе другая календарная зона, обрыв ответа после commit и истечение сессии. Ревью Standards и Spec завершены, открытых замечаний нет.
- Доступ: один аккаунт, Argon2id через pwdlib, непрозрачные серверные сессии на 30 дней; SQLite/SQLAlchemy и Alembic. Только два точных публичных маршрута: получение предварительного CSRF и вход. Остальные маршруты защищены общим middleware.
- HTTPS используется и в разработке; Vite проксирует API без смены Host. Cookie Secure не ослабляется локально. Прокси-заголовкам по умолчанию не доверяем.
- Пять неудачных попыток за скользящие 15 минут отдельно по источнику и логину, с сохранением в SQLite и сериализацией проверки.
- Проверки задачи 01: 10 HTTP-тестов с файловой SQLite, mypy, TypeScript/production-сборка, два Playwright-сценария (desktop и мобильный размер в Chromium). Браузерная регрессия охватывает допустимый пароль из 600 emoji.
