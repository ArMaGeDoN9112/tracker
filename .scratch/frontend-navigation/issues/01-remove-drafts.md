# 01: Удалить обработку черновиков во всех разделах

Status: resolved
Type: task
Blocked by: None (can start immediately)

**What to build:** пользователь получает начальную форму после ухода и возврата,
выхода, истечения сессии или перезагрузки. Несохранённые значения больше нигде
не сохраняются для последующего восстановления. Это самостоятельное изменение
текущего приложения, до перестройки навигации.

## Acceptance criteria

- [x] Сброс охватывает создание и исправление сахара/подколки, еды, воды, продуктов
  и порций, настройки быстрых объёмов воды, суточное расписание и временную базу.
- [x] Переход на другую страницу и возврат, в том числе через историю браузера,
  не восстанавливает незавершённую форму. Выход, истечение сессии, повторный вход
  и перезагрузка также не восстанавливают её.
- [x] Удалены механизмы удержания незавершённых форм между страницами/входами
  и связанные обещания в интерфейсе. Не добавлены автосохранение, предложения
  восстановления и предупреждения о потере ввода.
- [x] Обычный ввод в открытой форме работает. Выбор продукта, создание карточки
  из формы еды и возврат в текущий приём не теряют уже собранный состав:
  это шаги одного сценария, а не восстановление после ухода из него.
- [x] Повтор еды открывает заполненную форму с текущим временем; запись создаётся
  только после явного сохранения. Сообщения не называют её черновиком.
- [x] Сохранённые записи не изменяются от сброса формы. Переход или повторный вход
  не отправляет запись автоматически, ответ завершившегося запроса не восстанавливает
  закрытую форму, повтор неизвестной операции не создаёт дубликат.
- [x] Проверка редакций, обработка ошибок, сравнение при конфликте в открытой форме
  и глобальная отмена удаления сохраняются; срок отмены не продлевается.
- [x] Прежние браузерные проверки сохранения форм заменены проверками их сброса
  во всех перечисленных сценариях. Проверки защитных свойств операций сохранены.

- [x] Пройдены проверка типов, сборка и относящиеся к сценарию существующие браузерные проверки с настоящим тестовым API на компьютере и телефоне.
- [x] Документация текущего поведения обновлена; схема БД и контракты API сохранены, новые зависимости не добавлены.

## Общие ограничения

- Переиспользовать существующие операции и компоненты. Сохранить проверку редакций, защиту от дубликатов, явный повтор неизвестного запроса и глобальную отмену удаления с исходным серверным сроком.
- Черновики не сохраняются и не восстанавливаются между страницами или входами. Состав текущего приёма при выборе продукта внутри того же сценария не теряется.
- Данные загружаются при открытии страницы и после её собственных изменений, без фонового опроса и кнопок обновления. Время — HH:MM, расчёты — по Москве.
- До входа личные данные скрыты. Навигация и повторный вход не отправляют операции автоматически.
- Полные требования и согласованные проверки: [спецификация](../spec.md).

## Answer

Реализован только тикет 01. Формы создания и исправления сахара/подколки, еды,
воды, продуктов и порций, настройки кнопок воды, расписания и временной базы
сбрасываются при уходе, выходе, истечении сессии и перезагрузке. История браузера
не восстанавливает ввод. Выбор и создание продукта внутри текущего приёма
сохраняют его состав; повтор еды открывает новую форму с серверным временем
и требует явного сохранения.

Удержанные запросы отделены от полей формы: сохраняются UUID, тело, адрес и метод,
включая PUT исправления после закрытия редактора. Повтор только явный. Проверка
редакций, сравнение в открытой форме, ошибки подтверждённого сохранения и глобальная
отмена удаления с исходным сроком сохранены. Поздние ответы не открывают закрытые
формы; загрузка времени не перезаписывает ввод. Скрытый дневник не запускает
инициализацию формы или расчёт базы. API, схема БД и зависимости не изменены.
