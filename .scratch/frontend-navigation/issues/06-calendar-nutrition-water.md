# 06: Показать дневной график КБЖУ и итог воды в календаре

Status: resolved
Type: task
Blocked by: 04

**What to build:** вместо карточек приёмов пищи и списка добавлений воды пользователь
видит КБЖУ на одном графике по времени, итоги питания и общий объём воды за день.

## Acceptance criteria

- [x] Четыре ряда КБЖУ видны одновременно разными цветами с легендой; переключателя
  одиночного показателя нет. Над графиком — итоговые КБЖУ дня.
- [x] Калории имеют шкалу в ккал, БЖУ — общую шкалу в граммах. Горизонтальное
  положение данных соответствует времени приёма, а не номеру события.
- [x] Подсказка показывает время, численные значения, единицы и неполноту показателей;
  работает мышью, касанием/перемещением пальца и с клавиатуры.
- [x] Общий объём воды показан без списка отдельных добавлений и без нового графика воды.
- [x] Пустой день, неизвестные и неполные показатели, известные нули и приёмы
  с одинаковым HH:MM не дают ложных итогов или потери данных.
- [x] Карточки еды убраны из календаря; состав, подробности и операции доступны
  через переход в анализ питания выбранного дня.
- [x] Проверены выбранная дата, московские границы суток, загрузка, ошибка,
  устаревший ответ и отсутствие переполнения на телефоне и компьютере.

- [x] Пройдены проверка типов, сборка и относящиеся к сценарию существующие браузерные проверки с настоящим тестовым API на компьютере и телефоне.
- [x] Документация текущего поведения обновлена; схема БД и контракты API сохранены, новые зависимости не добавлены.

## Общие ограничения

- Переиспользовать существующие операции и компоненты. Сохранить проверку редакций, защиту от дубликатов, явный повтор неизвестного запроса и глобальную отмену удаления с исходным серверным сроком.
- Черновики не сохраняются и не восстанавливаются между страницами или входами. Состав текущего приёма при выборе продукта внутри того же сценария не теряется.
- Данные загружаются при открытии страницы и после её собственных изменений, без фонового опроса и кнопок обновления. Время — HH:MM, расчёты — по Москве.
- До входа личные данные скрыты. Навигация и повторный вход не отправляют операции автоматически.
- Полные требования и согласованные проверки: [спецификация](../spec.md).

Перед началом проверены `Status: resolved` тикета 04 и присутствие его коммита

В календаре вместо карточек еды — один график с четырьмя одновременно видимыми
рядами КБЖУ, разными цветами, штрихами и легендой. Калории используют левую шкалу
в ккал, БЖУ — общую правую шкалу в граммах; серверные итоги остаются над графиком.
Точки располагаются по точному времени приёма, включая миллисекунды, московские
границы и исторические переводы часов. Пропуски не становятся нулями и не
соединяются через неизвестные значения. Известные нули и неполнота сохраняются.

Подсказка показывает HH:MM, все четыре названия, значения, единицы и неполноту.
При совпадении точного момента перечисляет каждый приём отдельно; одинаковое
HH:MM у разных моментов не объединяется. Управление — наведение, касание,
горизонтальное движение пальца, стрелки, Home/End и глобальный Escape.
Вода показана только общим внесённым объёмом, без списка и нового графика.
Состав, подробности и операции доступны в анализе выбранного дня по существующей
ссылке «Записи питания». Пустой день показывает отсутствие записей.
