# 02: Сделать календарь главной и сгруппировать навигацию

Status: ready-for-agent
Type: task
Blocked by: 01

**What to build:** после входа открывается календарь со сводкой сегодня;
пользователь перемещается по верхнему уровню «Календарь / Диабет / Питание /
Настройки» и внутренним страницам предметного раздела.

## Acceptance criteria

- [ ] В диабете доступны «Ввод / Анализ / База», в питании — «Ввод / Анализ / Каталог».
  Переход в предметный раздел открывает ввод; прямая ссылка и история браузера
  восстанавливают указанную внутреннюю страницу.
- [ ] Календарь по умолчанию открывает сегодня по Москве вместе со сводкой;
  ссылка на другой день открывает соответствующие месяц и сводку.
- [ ] Прежние ссылки на существующие сценарии работают. Неизвестный раздел ведёт
  в календарь, ошибочная дата объясняется и не попадает в запросы.
- [ ] «Назад», «Вперёд», открытие ссылки в новой вкладке, обозначение текущей
  страницы и фокус работают. Незавершённые формы не восстанавливаются.
- [ ] Настройки, экспорт, резервирование и оба представления базы доступны.
- [ ] Навигация доступна на телефоне и компьютере, не перекрывает действия
  и не создаёт горизонтального переполнения страницы.
- [ ] На этом этапе существующее содержимое ввода и анализа остаётся доступным;
  перенос истории выполняется целиком в следующих двух тикетах.

- [ ] Пройдены проверка типов, сборка и относящиеся к сценарию существующие браузерные проверки с настоящим тестовым API на компьютере и телефоне.
- [ ] Документация текущего поведения обновлена; схема БД и контракты API сохранены, новые зависимости не добавлены.

## Общие ограничения

- Переиспользовать существующие операции и компоненты. Сохранить проверку редакций, защиту от дубликатов, явный повтор неизвестного запроса и глобальную отмену удаления с исходным серверным сроком.
- Черновики не сохраняются и не восстанавливаются между страницами или входами. Состав текущего приёма при выборе продукта внутри того же сценария не теряется.
- Данные загружаются при открытии страницы и после её собственных изменений, без фонового опроса и кнопок обновления. Время — HH:MM, расчёты — по Москве.
- До входа личные данные скрыты. Навигация и повторный вход не отправляют операции автоматически.
- Полные требования и согласованные проверки: [спецификация](../spec.md).
