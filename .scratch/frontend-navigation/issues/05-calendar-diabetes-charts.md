# 05: Показать дневные графики сахара, подколок и базы в календаре

Status: ready-for-agent
Type: task
Blocked by: 03

**What to build:** вместо текстовых карточек сахара/подколок пользователь видит
два графика точками с линиями, общую временную шкалу и синхронные подсказки;
ниже остаётся график базы.

## Acceptance criteria

- [ ] Сахар показан в ммоль/л, подколки — в единицах; границы, отметки и горизонтальное
  положение одного времени совпадают. Сахар и подколки — точки с линиями.
- [ ] Выбор времени синхронно подсвечивается на обоих графиках. Подсказки показывают
  фактические значения и отсутствие показателя, не выдают интерполяцию за измерение.
- [ ] Наведение, касание/перемещение пальца и клавиатура позволяют получать значения.
- [ ] График базы находится ниже и сохраняет подсказку периода/скорости, временную
  базу и обозначение неизвестных интервалов; список интервалов не возвращается.
- [ ] Пустой день, одна точка, только сахар, только подколка, ноль и события с одинаковым
  HH:MM показаны без потери данных. Московские границы суток и исторические
  повторяющиеся часы учитываются корректно.
- [ ] Текстовые карточки диабета убраны из календаря; исходные записи и действия
  доступны через переход в анализ выбранного дня.
- [ ] Проверены смена дня, загрузка, ошибка, устаревший ответ и компоновка на обоих устройствах.

- [ ] Пройдены проверка типов, сборка и относящиеся к сценарию существующие браузерные проверки с настоящим тестовым API на компьютере и телефоне.
- [ ] Документация текущего поведения обновлена; схема БД и контракты API сохранены, новые зависимости не добавлены.

## Общие ограничения

- Переиспользовать существующие операции и компоненты. Сохранить проверку редакций, защиту от дубликатов, явный повтор неизвестного запроса и глобальную отмену удаления с исходным серверным сроком.
- Черновики не сохраняются и не восстанавливаются между страницами или входами. Состав текущего приёма при выборе продукта внутри того же сценария не теряется.
- Данные загружаются при открытии страницы и после её собственных изменений, без фонового опроса и кнопок обновления. Время — HH:MM, расчёты — по Москве.
- До входа личные данные скрыты. Навигация и повторный вход не отправляют операции автоматически.
- Полные требования и согласованные проверки: [спецификация](../spec.md).
