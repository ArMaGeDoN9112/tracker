# 05: Показать дневные графики сахара, подколок и базы в календаре

Status: resolved
Type: task
Blocked by: 03

**What to build:** вместо текстовых карточек сахара/подколок пользователь видит
два графика точками с линиями, общую временную шкалу и синхронные подсказки;
ниже остаётся график базы.

## Acceptance criteria

- [x] Сахар показан в ммоль/л, подколки — в единицах; границы, отметки и горизонтальное
  положение одного времени совпадают. Сахар и подколки — точки с линиями.
- [x] Выбор времени синхронно подсвечивается на обоих графиках. Подсказки показывают
  фактические значения и отсутствие показателя, не выдают интерполяцию за измерение.
- [x] Наведение, касание/перемещение пальца и клавиатура позволяют получать значения.
- [x] График базы находится ниже и сохраняет подсказку периода/скорости, временную
  базу и обозначение неизвестных интервалов; список интервалов не возвращается.
- [x] Пустой день, одна точка, только сахар, только подколка, ноль и события с одинаковым
  HH:MM показаны без потери данных. Московские границы суток и исторические
  повторяющиеся часы учитываются корректно.
- [x] Текстовые карточки диабета убраны из календаря; исходные записи и действия
  доступны через переход в анализ выбранного дня.
- [x] Проверены смена дня, загрузка, ошибка, устаревший ответ и компоновка на обоих устройствах.

- [x] Пройдены проверка типов, сборка и относящиеся к сценарию существующие браузерные проверки с настоящим тестовым API на компьютере и телефоне.
- [x] Документация текущего поведения обновлена; схема БД и контракты API сохранены, новые зависимости не добавлены.

## Общие ограничения

- Переиспользовать существующие операции и компоненты. Сохранить проверку редакций, защиту от дубликатов, явный повтор неизвестного запроса и глобальную отмену удаления с исходным серверным сроком.
- Черновики не сохраняются и не восстанавливаются между страницами или входами. Состав текущего приёма при выборе продукта внутри того же сценария не теряется.
- Данные загружаются при открытии страницы и после её собственных изменений, без фонового опроса и кнопок обновления. Время — HH:MM, расчёты — по Москве.
- До входа личные данные скрыты. Навигация и повторный вход не отправляют операции автоматически.
- Полные требования и согласованные проверки: [спецификация](../spec.md).

## Answer

Завершено 28.10.2026.

Перед началом подтверждены `Status: resolved` тикета 03 и наличие его коммита
`c524492` в исходном HEAD `b1f3159` текущей ветки `master`. Рабочее дерево было чистым.

Календарь показывает два графика Recharts: сахар в ммоль/л и подколки в единицах,
точками с прямыми соединяющими линиями. Границы, отметки и горизонтальные координаты
времени совпадают. Выбор ближайшего точного момента общий для двух графиков;
подсказки выводят все исходные записи этого момента без интерполяции. Пропуск сахара
обозначен явно, подколка 0,0 остаётся нулём согласно существующему контракту API.
Разные моменты с одинаковым HH:MM доступны отдельно; совпадающие точные моменты
показывают каждую запись с её значениями.

Работают мышь, касание и горизонтальное перемещение пальца, стрелки, Home/End.
Escape скрывает обе подсказки, включая наведение без фокуса. Пустые дни и одиночные
показатели сохраняют шкалы. Границы московских суток определяются через часовой пояс,
а положение событий — через точные временные метки; повторяющиеся часы не схлопываются.
Ниже сохранены база, неизвестные интервалы, подсказки периода/скорости и временная база.
В календаре исторические сутки также показывают график базы, без возврата списка.
Другие вызовы существующего компонента базы сохраняют своё поведение.

Карточки записей диабета убраны; ссылка «Записи диабета» ведёт в анализ выбранного дня.
Питание и вода в календаре не изменялись. Тикет 06 не начинался.

Проверки:

- TDD: новый сценарий воспроизвёл отсутствие графиков до реализации.
- Календарные проверки — 10 passed (5 desktop + 5 phone) с настоящим одноразовым API.
  Проверены точные границы суток, исторический повторяющийся час, события через
  миллисекунду и в один точный момент, только сахар/подколка, ноль, пустой день,
  загрузка, ошибка, поздний ответ закрытого дня и переход к исходным записям.
- Итоговый полный Playwright — 206 passed (103 desktop + 103 phone), без повторов.
  Регрессия включает сессии, явные повторы прежних запросов, конфликты редакций,
  глобальную отмену с исходным серверным сроком, питание, воду и временную базу.
- TypeScript и production-сборка прошли; сохраняется предупреждение Vite о JS > 500 kB.
- Полный pytest в штатном tracker-checks — 469 passed, 8 предупреждений зависимостей.
  Исходники Python, миграции, scripts и тесты в образе сверены с текущей веткой:
  различий нет. Бэкенд в рамках тикета не менялся.
- Просмотрены снимки узкого и широкого интерфейса; видимость обеих линий,
  синхронные отметки времени и отсутствие горизонтального переполнения проверены.
  Движение пальца проверено через Chromium touch events в мобильном профиле.
- Визуальная приёмка выявила невидимую линию подколок из-за недоступной цветовой
  переменной. Исправлено; отдельная браузерная проверка сначала воспроизвела дефект,
  затем прошла. Замечание о глобальном Escape также исправлено и покрыто проверкой.
