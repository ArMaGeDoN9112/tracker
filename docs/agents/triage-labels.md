# Triage labels

Use these exact strings for the corresponding roles.

| Role / Status | Meaning |
| --- | --- |
| needs-triage | Maintainer evaluation needed |
| needs-info | More information needed from reporter |
| ready-for-agent | Fully specified, ready for an autonomous agent |
| ready-for-human | Requires human implementation |
| wontfix | Will not be actioned |
